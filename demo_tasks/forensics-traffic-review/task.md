# 流量证据包分析

## 任务描述

给定网络流量包，分析异常登录、文件传输和隐藏线索，提取关键证据并输出可复核的取证分析报告。

## 输入材料

- 流量文件: `traffic.pcap`
- 可选材料: 事件时间范围、可疑 IP、业务背景
- 关注点: HTTP 会话、DNS 查询、文件传输、编码载荷

## 预期工具链

- `file`: 文件类型检查
- `tshark`: 流量统计与会话提取
- `binwalk` / `foremost`: 文件和载荷恢复
- `exiftool`: 元数据检查

## 验收点

- 能识别为取证分析场景
- 能生成流量概览、会话筛选、载荷还原和证据归档流程
- 能形成证据、产物和成果审核记录
