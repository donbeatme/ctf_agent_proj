# 逆向样本算法还原

## 任务描述

给定可执行样本，分析输入校验逻辑和关键算法路径，还原校验流程并输出可验证的分析结论。

## 输入材料

- 样本文件: `checker.bin`
- 可选材料: 运行提示、样本哈希、输入输出样例
- 关注点: 字符串线索、关键函数、控制流、混淆逻辑

## 预期工具链

- `file` / `strings`: 样本基础信息提取
- `ghidra` / `radare2`: 静态分析
- `angr`: 路径探索辅助

## 验收点

- 能识别为逆向分析场景
- 能生成静态分析、路径定位、算法还原和验证流程
- 能形成证据、产物和成果审核记录
