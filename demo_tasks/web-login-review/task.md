# Web 登录接口风险研判

## 任务描述

目标 Web 服务存在登录接口、资料上传接口和若干 API 入口。请识别可疑参数、检查认证绕过和文件上传风险，并输出可复核的风险研判结果。

## 输入材料

- 目标地址: `http://target.local:8080`
- 入口路径: `/login`, `/upload`, `/api/profile`
- 关注点: 认证逻辑、参数校验、上传类型限制、会话安全

## 预期工具链

- `curl` / `httpx`: 请求采样和响应比对
- `sqlmap`: 参数注入风险辅助验证
- 浏览器开发者工具: 表单、Cookie 和接口观察

## 验收点

- 能识别为 Web 安全场景
- 能生成分步骤研判计划
- 能形成证据、产物和成果审核记录
