# RSA 参数安全分析

## 任务描述

给定 RSA 公钥参数 `n`、`e` 与密文 `c`，判断是否存在低指数、共享因子、参数复用或弱随机风险，并输出完整推导与验证结果。

## 输入材料

- 参数文本: `n`, `e`, `c`
- 可选附件: PEM 公钥、参数 JSON 或样本密文
- 关注点: 公因子、低指数、模数位数、填充方式

## 预期工具链

- `python`: 参数解析和验证脚本
- `sympy`: 数论辅助计算
- `z3`: 约束求解辅助
- `pycryptodome`: 密码原语解析

## 验收点

- 能识别为密码安全场景
- 能生成参数提取、风险判断、脚本验证链路
- 能形成证据、产物和成果审核记录
